# Grading vocabulary

`hsk2.json` contains the cumulative simplified-word lists for classic HSK 2.0
levels 1–6. The Mandarin Workshop uses these lists as a deterministic grading
baseline because Du Chinese maps its six reader levels to the same HSK 1–6
bands.

Source: [`drkameleon/complete-hsk-vocabulary`](https://github.com/drkameleon/complete-hsk-vocabulary), pinned to `v1.4` and used under the MIT license preserved beside the data. Run `python -m workshop.sync_hsk_vocab` to refresh the generated file.
